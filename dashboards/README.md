# Power BI Dashboard Previews

The project contains three production-style Power BI report pages.

## 1. Sales Performance

Executive view of sales, profit, margin, YoY growth, monthly performance and regional contribution.

**Core KPIs:**
- Sales: $20.40M
- Profit: $2.58M
- Profit Margin: 12.6%
- YoY Sales Growth: 46.9%
- Orders: 48,620
- Customers: 12,840

## 2. Customer Insights

Customer segmentation, revenue contribution, regional customer distribution, new/returning activity, order frequency and customer-level performance.

## 3. Regional & Product Performance

Regional sales/profit, category performance, product rankings, profitability and monthly/quarterly performance.

## Image files

When dashboard PNG previews are added to this directory, use these names:

```text
dashboards/
├── sales-performance.png
├── customer-insights.png
└── regional-product-performance.png
```

The images are portfolio previews only; the private `.pbix` and underlying confidential data remain excluded.
